# Fan Guys Tools Portal

The home-screen launcher for Fan Guys: the company websites (BigFanGuys.com, fanospro.com, fanospro.app), Fan Guys Tools and Exam Pro, each one tap away.

Fan Guys Books isn't listed here on purpose; it has its own home-screen icon.

**Open it:** https://thefanguys.github.io/

To add a tool, add a new button in index.html under the right section.

Hosted on GitHub Pages. Add it to your iPhone home screen from Safari's Share menu.
